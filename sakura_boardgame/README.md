# Sakura 棋盘游戏插件

让夜乃樱和你玩**双人回合制桌游**，配一张**可拖拽的网页棋盘**。设计原则：代码管规则和棋盘（绝对不出错），夜乃樱管决策和嘴（每一步都要有解说和情绪）。

内置两种游戏：

| 游戏 | 玩法 | 对抗 |
|---|---|---|
| 大富翁（monopoly） | **第二横滨市**城市地图上的地产经营：掷骰沿街道走格、遇岔路选方向、买地收租升级抵押、四街区垄断加成、九种格子、24 张原作事件卡；破产判负，回合上限按总资产定胜负 | 对战 |
| 五子棋（gomoku） | 十五路棋盘；**开局双方各掷骰决定先后手**；夜乃樱的棋由内置 AI 代算，可选难度与棋风 | 对战 |

## 安装

从 [Releases](https://github.com/0115ayasakura/Sakura-boardgame/releases) 下载 `sakura-boardgame-plugin.zip`，然后：

1. Sakura「设置 → 插件 → **安装插件…** → **从 ZIP 安装…**」，选中这个 zip。
   （也可以选「从文件夹安装…」，指向本目录——含 `plugin.yaml` 的那一层。）
2. 装好后插件默认是**未启用**状态，在插件列表里打开它的开关。
3. 启用后聊天侧出现 6 个 `boardgame_*` 工具，并启动一个可读的本地棋盘服务器（仅 127.0.0.1）。
4. 「插件设置」可调：**地图来源（第二横滨市 / 随机地图）**、骰子面数、随机地图规模（12–96 格）、
   五子棋难度、**五子棋棋风**、**打法性格**、自动打开棋盘、夜乃樱自动反应。

> **更新要先卸载**（Sakura 不允许同 id 覆盖安装）：插件页「卸载插件」→ 再装新版，设置与数据会保留。

## 网页棋盘（全程可交互，不占用聊天）

打开后你可以在网页上完成所有操作，夜乃樱只负责她自己的回合和解说：

- **拖拽平移 / 滚轮缩放**地图；格子按离视觉中心的距离**缩放景深**（中心大、边缘小），缩放平滑过渡
- **开局视角有缩放下限**（不会把整张图缩到看不清格子）；要看全图往外滚一格即可，之后自由拖动
- **城市规划式地图**：城市由**街道网络 + 街区**构成——一条外圈主环、三条主动脉、十一条支街。
  格子落在街道路口上，因此地图天然连通、没有死胡同
- **随机地图（切「地图来源」用）**：一条蛇形主环 + 若干**短支线**。支线只连接主路上相距 2–4 步、
  几何上也贴近的两个节点（贴着主干鼓出一个小包），不再横跨全图；主环画成宽路+蓝色虚线中线，
  支线是窄灰路，结构一眼能看出来
- **行进方向由地图规定**：主环是**单向**的，方向就是主环的节点顺序——从起点出发**第一格必须是学园正门**，
  不能倒着走；支街是双向的，可以拐进去再退出来。主环上的蓝色方向箭头按**真实路径弧长**摆放，严格贴在路面上
- **主路与支街在视觉上分得很开**：主环最宽（白色路面 + 蓝色路肩 + 蓝色虚线中线），主动脉中等宽，支街最窄且路面浅灰；
  画的时候分三遍（先所有路肩 → 再所有路面 → 最后重画主环），所以支街是**汇入**主环，不会压在主路上盖出缺口
- **四个街区用柔和色块 + 区域名标出**（学园区 / 街市 / 住宅区 / 荒废街区）。相邻街区**共用同一条边界曲线**，
  因此四块严丝合缝：一直铺到地图边框（不留白）、彼此也不重叠（不混色）；区域名画在最上层并带白描边，不会被绿化挡住
- 底图包含**立体建筑群、绿地（校区草坪 / 公园 / 海边绿地）、右下角的海与两个水塘**；
  水体与色块都裁在地图边框内，不会漫出去
- **地标画成地图图钉**：钉尖指向路线上的格子锚点、统一抬高到**路面边缘**（图钉与路的间距一致），路线不会被盖住
- **棋子头像是大头像，且地图缩小时会反向放大**，任何缩放级别下都能一眼看到双方在哪
- 移动时**把这一步走过的路线画成一条彩线**（沿途点出经过的格子），棋子顺着线滑过去，不再是逐格跳动
- **事件卡写明效果**：抽到卡时对局记录与弹出的卡面都会带上实际效果（如「（效果：获得 ¥110）」），
  不只是卡的文案
- **操作按钮固定在棋盘上方**：掷骰子、岔路选向、地产决策、请夜乃樱行动都在这里
- **掷骰子**按钮 → 骰子摇动动画 → **棋子沿路径逐格跳动前进**
- **岔路**时弹出方向按钮，显示每个方向通向的格子名
- 地产**买入 / 升级 / 抵押 / 赎回 / 卖掉 / 跳过**全部按钮化
- **五子棋**：暖木色棋盘、白子深描边（对比清晰）；直接点交叉点落子；难度（入门/进阶/困难）与棋风（稳健/均衡/进攻）在侧栏切换
- **请夜乃樱行动**按钮：让她走她自己的回合
- **玩法说明**弹窗：规则速查 + 九种格子图例 + 24 张事件卡完整图鉴
- 侧栏显示双方**地产数量、抵押数量、当前租金收益（对手踩到能收的钱）和垄断地段**，以及对局记录与骰子

## 第二横滨市（默认地图）

地图是手工设计的定值数据，唯一事实来源是 `city_map.py`，改一张表就能改地图：

| 街区 | 配色 | 地标 |
|---|---|---|
| 学园区 | <span style="color:#4a8bc9">#4a8bc9</span> | 学园正门、学生会室、图书馆委员会、探索委员会、无调图书馆、地下大圣堂、**汉加米塔**、学园游泳池、弓道场 |
| 街市 | <span style="color:#d95a72">#d95a72</span> | 家庭餐厅、KTV包厢、情侣酒店、英国人街、Esports街区、观景台、便利店、游戏中心 |
| 住宅区 | <span style="color:#3f9e83">#3f9e83</span> | 樱的公寓、玩家的公寓、公园、流浪猫的据点、海边步道、旧书店、面包店、旧澡堂、海边长椅 |
| 荒废街区 | <span style="color:#4a5470">#4a5470</span> | 东京巨壁、地下铁道、下水道井盖、黑列车车站、崩月家、废置兵舍、废弃医院、防空洞、崩月家后巷 |

全图 **57 格**（29 块地产 + 13 日常 + 7 NAVI播报 + 起点/补助×2/税×2/猫/炭化之人/黑列车）。
**地产同时铺在主环和支街上**——每条岔路都有自己的地标，拐进去才有理由，不是空走两格。
`city_map.validate_layout()` 会自动校验：连通性、无死胡同（度数 ≥ 2）、任意两格间距 ≥ 0.92、
没有格子落在水里、每块地产都在自己街区内、路口（度 ≥ 3）≥ 3 处、构成比例合理。
**改动地图后请跑一次 `python sakura_boardgame\city_map.py`，输出"校验：通过 ✓"才算改对。**

自定义地图：编辑 `city_map.py` 的 `DISTRICTS`（四个街区的多边形，中心共用 `CUR` 一点）、
`STREETS`（街道折线、布点步长、`role`）、`PROPERTY_NAMES`（每街区的地标与档位）、
`SPECIAL_CYCLE`（无主格序列）即可，格子坐标会沿街道自动重新布点。
`decor()` 会把街区/绿地/水体/路网/建筑一起下发给网页，`roads()` 按 `role` 区分主环、主动脉与支街。

地图上另有绿地 `GREEN_ZONES` 与建筑生成器 `buildings()`——预览页 `boardgame_art/render_city_preview.py`
和网页底图读的是**同一份数据**，两边不会走样。

> 城市图固定一张，只有骰子/事件卡/地产归属每局变化；想要每局不同的地形，把「地图来源」切到**随机地图**。

## 事件卡收益平衡

（可用 `boardgame_tests/card_balance.py` 复算）：24 张共 18 张现金卡，
合计 **+740**，均值 **+41.1/张**；正收益 11 张均值 +150，负收益 7 张均值 −130。
整体**略偏正收益**——这是有意的：陪伴向的小游戏里，事件格更多是"惊喜"而不是"惩罚"，
也让夜乃樱有更多可以得意或嘴硬的空间。想要更硬核的平衡（期望值归零或偏负），
把负收益卡的 amount 再调大即可，引擎不依赖具体数值。

## 两种玩法通道

1. **网页（推荐）**：你在网页上点按钮推进；轮到她时点「请夜乃樱行动」。
2. **聊天**：直接说「掷骰子」「买下它」「走左边」等，她调用工具执行——适合你想听她即兴发挥的时候。

两者共用同一局棋（存档、日志、上下文快照都是同一份）。

## 对局状态为什么不会记错

插件注册了动态上下文贡献者：对局进行中时每轮 Prompt 都注入**权威棋盘快照**（双方位置、邻接关系、待决策项、最近动态），并明确要求她以快照为准。棋局持久化在插件私有数据目录，插件重载或 Sakura 重启后继续有效（旧版存档会自动作废重开）。

## 大富翁规则速查

- 掷骰走相应格数；**主环是单向的**（方向 = 主环顺序，起点出发第一格就是学园正门），
  支街双向；走到路口（有多个可行方向）时由你选方向
- 起始资金 **¥1400**；起点工资 **¥250**（经过或落在起点都算）
- 地产四个街区（价格 = 档位 ×60，即 ¥60/¥120/¥180）：
  <span style="color:#4a8bc9">学园区</span> / <span style="color:#d95a72">街市</span> / <span style="color:#3f9e83">住宅区</span> / <span style="color:#4a5470">荒废街区</span>
- **垄断**：持有同一街区 **一半**地产（且无一抵押、街区至少 2 块地）→ 租金 ×2
- 租金 = 现价 ÷2 ×（升级 ×2）×（垄断 ×2）；地价随回合数上涨（每 8 回合 +¥20，封顶 1.5 倍）
- 抵押回收半价（按现价，与主动抵押同口径）、期间不收租不参与垄断；赎回付六成价；卖地回收三分之一
- 付不起账单 → 强制逐个抵押（先便宜后贵）；全部抵押仍不够 → 破产，剩余资产（含抵押状态）移交债主
- 九种格子：起点 ★ / 地产 / 特别会计 / 学园补助 / 日常一幕 / 灰色的流浪猫 / 炭化之人 / 黑列车 / NAVI播报
- 回合上限 = max(36, 地图格数 ×1.5)，到顶按**总资产**（现金 + 地产现价 ×0.6）判胜负（城市图 57 格 ≈ 86 步 ≈ 每人 1.5 圈）

### 当前平衡（`boardgame_tests/econ_report.py` 跑批实测，200 局双方都买）

| 指标 | 数值 |
|---|---|
| 结束方式 | 破产 10% / 打满上限 90% |
| 租金事件 | **5.5 笔/局**（单笔中位 ¥90、最高 ¥540） |
| 垄断出现率 | **75%** 的对局（终局被买走的 16.9/29 处） |
| 每人每局 | 买 8.6 处地 ¥1350、升级 2 次、收租 ¥316、缴税/车费 ¥410、工资 ¥445 |
| 被迫抵押 | 1.76 次/局（有底金时不容易被逼死） |
| 成败关键 | **买地 vs 只攒钱 ≈ 50% : 50%**（判定按总资产，买地不吃亏也不无脑占优） |

> 平衡旋钮都在 `engine.py` 顶部：`MONOPOLY_PRICE_UNIT`（地价单位）、`MONOPOLY_START_CASH` /
> `MONOPOLY_PASS_START`（一局里的钱）、`MONOPOLY_ROUNDS_PER_CELL`（局长度）、
> `MONOPOLY_HOLD_SHARE`（垄断门槛）、`MONOPOLY_PROPERTY_SCORE`（终局地产折价）、
> `MONOPOLY_RENT_DIVISOR`（租金比例）。改完跑 `econ_report.py` 就能看到前后对比。

## 五子棋 AI

纯标准库自研（`gomoku_ai.py`）：棋型评估 + 候选点生成 + alpha-beta 搜索，单步思考 < 2 秒。

- **难度**：入门（贪心 + 随机扰动，会漏招）/ 进阶（浅搜）/ 困难（深搜）
- **棋风**：0–100 的进攻倾向，越大越爱主动做杀、越小越优先拆招。默认 45（均衡）。
  **这个参数确实会改变 AI 的选点**（`aggression` 会加权进攻分与防守分），不是摆设。
- 两种调整路径：插件设置里的「五子棋棋风」是**默认值**，网页上的「稳健/均衡/进攻」是**临时覆盖**，用来当场试手感。
- 棋风目前由设置项决定（不跟角色卡走）——大富翁那边的打法性格才是读角色卡推出来的（见下）。

## 未来计划：3–4 人局（暂缓）

按跑批测算，**现在这张 57 格 / 29 处地产的城市图其实更适合 3–4 人**：一局里的钱 ≈ 人数 ×（起始 + 工资），
4 人时约 ¥4600，而棋盘总价 ¥3420（钱/地价 ≈ 1.35）——**能把棋盘买空**，租金成为主要资金流，
这正是大富翁该有的形态。双人局反而只有 0.77，只能买走一半（这也是起始资金从 ¥1000 调到 ¥1400 的原因）。

要动的地方（先记下来，等宿主支持了再做）：

1. **收入方式**：现在每人靠"绕一圈领一次工资"，4 人分摊同一套回合上限时每人只掷约 21 次骰 ≈ 0.8 圈。
   要么把上限按人数放大（`格数 ×1.5 × 人数/2`，4 人 ≈ 172 步），要么改成**每回合津贴**，
   这样固定上限对任何人数都成立。
2. **引擎**：`PLAYERS` 目前写死两人，`_other()` 换手、`winner` 单人、`collect_each/pay_each`
   这些卡都是"对方"——要改成 N 人轮转、"最后一个没破产的人赢"、"其他所有人"。
3. **插件**：另外 2–3 个 AI 座位由谁驾驶（同一套角色卡性格，或玩家分别指定）。
4. **网页**：侧栏两行玩家面板、两个棋子位（`tokenImgs`、`for (const p of ["user","sakura"])`）、
   「请夜乃樱行动」按钮都要按人数展开。
5. **前置条件**：**Sakura 本体与现有第三方插件暂不支持多开角色 agent**——多出来的人只能是"无名 AI 座位"，
   没法各自是独立角色。所以这一项先列为将来打算做的事。

## 她的打法性格（大富翁）

夜乃樱买不买地、升不升级、岔路走哪边，**由角色卡正文推出来**——插件开局时通过宿主服务
`sakura.host.character.current()["systemPrompt"]` 读到角色卡全文（`characters/<角色>/card.md`），
按里面的措辞给四个倾向打分（`persona.py`，词表就是全部逻辑）：

| 角色卡里的措辞 | 倾向 | 棋盘上的表现 |
|---|---|---|
| 冷静／克制／理性／掂量／谨慎／精打细算／不乱花／节俭 | 谨慎 | 买地前先留一笔底金（默认 ¥120–380，谨慎的留得多） |
| 好胜／不服输／胜负欲／要强／宣示主权／不后悔 | 好胜 | 更愿意升级；岔路上更愿意往自己已有地产的街区钻 |
| 好奇／闲逛／逛逛／散步／探索／孩子气／被可爱的东西／猫 | 好奇 | 岔路上更愿意拐进支街逛 |
| 温柔／体贴／照顾／宠／心疼／谦让／手下留情／心软 | 心软 | 总资产领先 25% 以上时，偶尔放一块无主地给玩家 |

- **改角色卡就能改她的棋风**：下一局生效，不用重启插件；打分是"命中分/(命中分+饱和常数)"，
  饱和常数随卡的长度走，免得两万字的长卡把四个倾向全刷满。
- 插件设置里的「打法性格」可以直接选 稳健／进取／随性／温柔 覆盖角色卡（或选「跟随角色卡」）。
- 她的上下文里会写明"你现在的打法性格：…"，所以**解说和落子是一致的**（谨慎的她不会嘴上莽撞）。
- 夜乃桜现在这张卡推出来的大致是：**好胜 + 好奇 + 心软，底金留 ¥270 上下**——
  也就是「先看现金再出手，但机会来了会抢、岔路爱拐进去逛、领先多了会让一手」。
- AI 会给出落子理由（如「在此做出活三」「先拆掉对方的活四」），写进对局记录供她解说。

## 夜乃樱的反应机制（重要限制）

新版 Sakura **没有**给插件「让角色在桌面聊天气泡主动开口」的接口。本插件用两条通道：

1. **聊天触发（稳定）**：你在聊天里说一句话（如「该你了」「这步你怎么看」），她会读到棋盘快照并回应。
2. **网页按钮**：点「请夜乃樱行动」后，插件替她执行回合，并通过 `sakura.host.mobile` 注入一条播报让她生成反应。**该反应会写入聊天记录，但桌面气泡可能不会实时弹出**（受宿主限制）。
   可在设置里关闭「夜乃樱自动反应」。

棋盘上的格子图标、玩家头像、**整张城市底图**（街区、建筑、绿地、水体、路网）均为**自绘 SVG / 程序生成**，以保证风格统一、不含残留文字。
**素材仅供本地个人使用，请勿再分发。**

地标插画（POI 缩略图）**已用本地 ComfyUI 全部出好**：Counterfeit-V3.0 fp16 + EasyNegativeV2，512px，
统一风格模板 + 固定 seed，共 35 张（29 块在用地标 + 6 张备用）。文件名与 `city_map.py` 里的 `icon` 字段一一对应
（`poi-gate` → `art/poi/gate.png`），网页按 `/art/poi/<key>.png` 读取；**图片缺失时图钉自动退回通用图标**，不会出现破图。

出图与审图脚本都在 `boardgame_art/`：
`gen_poi_all.py`（全量出图，512px 约 2 秒/张）· `regen_poi.py` / `regen_poi2.py`（重出不满意的）
· `make_contact_sheet.py`（拼成一张总览图便于审图）· `check_poi_coverage.py`（核对每块地标都有图）。
ComfyUI 部署与启动见记忆里的 `comfyui-local-setup`（`D:\ComfyUI`，127.0.0.1:8188）。

替换玩家棋子头像：把 `art/avatar_user.png`（或改 `board.html` 里的引用为同名 .png）放进本目录即可。

## 扩展新游戏

在 `engine.py` 加一个游戏类，满足 `kind`、`summary()`、`render()`、`to_dict()/from_dict()`、自己的操作方法（非法操作抛 `GameError`），再到 `plugin.py` 的 `create_game`/`restore_game` 分发、工具注册、`board.html` 页签与渲染各加一条即可。

## 排障

- 运行日志窗口的「插件」页按「棋盘游戏」筛选；文件在 `data/logs/sakura-plugins.log`
- 棋盘页面打不开 / 角色说"棋盘没打开"：**棋盘地址每轮都在角色的上下文里**（插件的上下文贡献者会注入
  `棋盘页面地址：http://127.0.0.1:端口/`），直接问她要地址即可；也可以在插件设置里点「打开棋盘页面」。
  另外**网页自己就能开局**：顶部有开局按钮，没开局时直接点掷骰子也会自动开一局，
  所以即使模型没有调用工具，也不影响你打开网页开玩。
  插件会依次尝试 `webbrowser.open` → `os.startfile` → `cmd /c start` 三种方式打开浏览器，
  全都失败才放弃，并在日志里留下 `BOARD_OPEN_FAILED` 与地址（日志窗口的「插件」页可查）。
- 网页按钮报错：错误会以浮层提示显示（引擎的规则性拒绝也走这里）
- 修改源码后需在插件页重新安装该文件夹并 reload
