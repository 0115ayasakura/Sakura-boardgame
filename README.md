# 桜のボードゲーム室 · Sakura 棋盘游戏插件

给桌面角色扮演应用 [Sakura](https://github.com/Rvosy/Sakura) 写的**双人回合制桌游插件**：
引擎管规则，角色管解说。你和夜乃樱在同一张**可拖拽的网页棋盘**上对局，她在每一步给出口吻一致的解说。

完全使用 **Python 标准库**（无第三方依赖），美术除角色立绘外全部**程序生成或本地 AI 生成**。

内置两个游戏：

| 游戏 | 玩法 |
|---|---|
| **大富翁** | 「第二横滨市」城市地图上的地产经营：掷骰沿街道走格、遇岔路选方向、买地收租升级抵押、四街区垄断加成、九种格子、24 张原作事件卡；破产判负，回合上限按现金定胜负 |
| **五子棋** | 十五路棋盘；开局双方各掷骰决定先后手；夜乃樱的棋由内置 AI 代算，可选难度与棋风 |

## 特性

**网页棋盘（全程可交互，不占聊天）**
- 拖拽平移 / 滚轮缩放；开局视角有缩放下限，格子和棋子不会小到看不清
- **地图来源可切换**：手工城市图「第二横滨市」/ 程序生成的随机地图（侧栏一键切换，下一局生效）
- 城市图：四个街区用柔和色块标出，底层有立体建筑、绿地、海与河道；**地标画成地图图钉**，钉尖指向路线上的锚点
- **地标插画**：29 块地产各有 AI 生成的一图一景，图片缺失时自动退回通用图标
- **行进方向由地图规定**：主环单向（从起点出发第一格必定是学园正门），主环上画着蓝色方向箭头；支街双向
- 移动时把走过的路线画成一条彩线，棋子沿线滑行
- 事件效果直接写在对局记录里（如「（效果：获得 ¥110）」「（-¥300）」），不用心算

**随机地图**：抖动的格子位置 + 贪心最近邻成环 + 2-opt 松解，保证**主路不自交叉、支线不穿主线、支线至少跨过两个节点**；间距按 1.95 格铺开，图钉不会互相挤。（`tools/check_random_rules.py` 可复算这些指标）

**五子棋 AI**：纯标准库自研棋型评估 + alpha-beta，难度（入门/进阶/困难）× 棋风（0–100 进攻倾向）都会真正改变选点，并给出落子理由供角色解说。

**出问题了也能玩**：角色的工具调用未必可靠，所以插件做了三条兜底——棋盘地址每轮都在角色上下文里、开局回复里带地址、**网页自己就能开局**（点掷骰子时若还没对局会自动开一局）。

## 安装

1. Sakura「设置 → 插件 → 安装文件夹」，指向 `sakura_boardgame` 目录（含 `plugin.yaml` 的那个）。
2. 启用后聊天侧出现 6 个 `boardgame_*` 工具，并启动一个只读的本地棋盘服务器（仅监听 127.0.0.1）。
3. 「插件设置」可调：地图来源、骰子面数、随机地图规模、五子棋难度与棋风、自动打开棋盘、角色自动反应。

> 需要 Sakura 1.1.0 及以上。本插件用系统级浏览器调用打开棋盘，不依赖已移除的 Playwright 网页插件。

### 装好后怎么验收

1. 说「开一局大富翁」→ 浏览器自动打开棋盘，默认是第二横滨市（57 格）
2. 侧栏「地图来源」切到**随机地图** → 重开一局，应变成随机布局（约 28 格）
3. 点「掷骰子」能走格、骰子卡显示点数、走过的路线被画出来
4. 踩到黑列车等格子，记录里带金额
5. 点「请夜乃樱行动」→ **一次点按**走完她的整个回合（连续岔路也会走完）
6. 切「五子棋」页签直接下棋；页签顶部也有「重开一局」

### 角色卡

`docs/角色卡补充.txt` 是要粘进角色卡的一节提示词（称呼、解说方式、地名说话、输赢反应、AI 棋风的说法）。
**这是让角色表现正确的关键**，插件代码管不了她的口吻。

## 开发与自测

```bash
python boardgame_tests/test_engine.py          # 引擎 25 项测试
python boardgame_tests/test_plugin_smoke.py    # 插件集成测试（假宿主，含开局/网页操作/存档）
python boardgame_tests/preview_server.py monopoly   # 本地起一局，浏览器看棋盘
python tools/preinstall_check.py               # 安装前体检（资产齐全 / 无硬编码路径）
python tools/map_report.py                     # 打印城市图结构：主环顺序、支路、路口、地产归属
python tools/check_random_rules.py             # 随机地图指标：锐角 / 交叉 / 支线跨步 / 最小间距
python tools/smoke_fresh_install.py            # 用全新数据目录模拟一次"刚装好"
```

改地图只看 `sakura_boardgame/city_map.py` 一张表（街区多边形、街道折线、地标、事件格序列），
改完跑 `python sakura_boardgame/city_map.py`，输出「校验：通过 ✓」才算改对。

## 关于开发方式

**本项目的全部代码与文档均为 AI 编写**，在人工提出需求、验收与反馈的协作下完成，**不含任何手写代码**。
美术资源同样不是手工绘制：地图（街区、建筑、绿地、水体、路网）由 `city_map.py` 程序生成，
35 张地标插画由本地 ComfyUI 生成，图标与玩家头像是代码里的内联 SVG。

## 已知限制

- **角色不一定主动调用工具**：实测在聊天里说「开一局」她可能只做口头解说（她的角色卡写着"操作在网页上完成"）。
  明确要求（「调用 boardgame_start」）时是可以调通的；插件侧已做兜底，不依赖她也能玩。
- **自动播报没有语音**：网页「请夜乃樱行动」触发的那轮解说走的是插件注入通道，宿主不为其生成语音；
  想听她出声，就在正常聊天里问她一句。
- 随机地图平均每张图仍有约 4 处偏尖的转角（已优先保证不交叉）。
- 角色卡补充里的地名与地标按「第二横滨市」设定编写，换成随机地图时她会改用格子上的通用名。
