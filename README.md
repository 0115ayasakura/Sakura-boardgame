# Sakura 棋盘游戏 · v1.0.3-pre

适用于 [Sakura](https://github.com/Rvosy/Sakura) **1.3.6 及以上**的可选插件。支持大富翁和五子棋：**引擎执行规则与结算，当前角色的真实 Agent 选择行动并解说**。角色姓名、立绘及引导跟随当前角色。

这是预览版，不代表全部流程已完成验收。Python 后端仅使用标准库；网页 3D 使用随包提供的 Three.js。

## 安装和更新

1. 从 [Releases](https://github.com/0115ayasakura/Sakura-boardgame/releases) 下载 **sakura-boardgame-plugin.zip**，不要选 GitHub 自动生成的 Source code ZIP。
2. 在 Sakura「设置 → 插件 → 安装插件 → 从 ZIP 安装」中选择它；也可解压后从包含 `plugin.yaml` 的文件夹安装。
3. 安装后手动启用「棋盘游戏」，通过聊天输入区的棋盘入口或插件设置打开网页。服务器仅监听 `127.0.0.1`，端口可能随重载变化。
4. 更新前备份 Sakura 数据目录内 `plugins/local.sakura.boardgame` 的存档与自定义引导。按 Sakura 的同 ID 插件更新/修复流程操作；不要手工删除数据目录。升级前的完整主程序数据备份更稳妥。


## 玩法

- **大富翁**：第二横滨市城市图与固定格子棋盘；选路、地产经营、效果与道具、商店、塔探索、黑列车事件与收益结算。
- **五子棋**：15 路棋盘，开局掷骰决定先后手；角色通过 Agent 工具提交坐标。
- **真实角色决策**：默认 `agent` 驱动，每个工具提交一个合法动作。选路、买地等属于同一次骰子回合，不额外增加回合数。
- **显式算法模式**：设置中选择 `algorithm` 后使用本地算法；Agent 失败或过期时，也可手动选择「由算法代操作」完成当前动作，不永久切换模式。不会自动降级。
- **暂停与继续**：「暂停并离开」成功后保留进度、撤销旧 Agent 决策，可收起或关闭页面；回来点击「继续对局」。恢复保留自动模式选择，不直接掷骰或消费待选项；已经生成的语音可能继续。
- **结果与等待**：重要结果需点「已了解，继续」，轻提示自动收起；等待区显示阶段和耗时。黑列车失败会保留卡内恢复入口，结果不确定时先核态，不自动重发。
- **聊天隔离**：按本轮输入决定是否注入棋盘快照；未结束存档、旧聊天或页面打开，不会把无关闲聊自动当成正在玩。
- **结算记录**：现金、票根、收益、产权等以引擎和网页记录为准；解说不是规则执行凭据。

## v1.0.3-pre：连续选择与交互节奏

- 角色先完成本次授权内的选路、选骰、地产及事件选择，再统一解说；每个 token 仍只提交一次动作，最多串接8个动作，不自动开始下一次掷骰，不跨越塔及玩家行动边界。
- 增加超时/失败后的手动算法代操作、可持久保存的暂停与恢复，以及当前话题上下文隔离。
- 修复黑列车卡内失败反馈、连续选路后的骰点呈现；重要事件显式确认，旧确认或计时回调不能关闭下一张结果卡。
- 内置引导统一为先选择、后自然简短回应。**插件 ZIP 不包含 Sakura 宿主修改**：本机调过的全局分段协议不随插件分发，原版宿主或自定义角色/引导仍可能让回复偏长。

## v1.0.2 Preview：市场收录兼容修正

- 市场发布使用 `registry` 分支及版本标签：`plugin.yaml` 和入口位于根目录；`main` 仍保留开发源码与测试，不把开发根目录直接交给市场打包。
- 两份 3D 场景中大于 1024 像素的纹理缩至最长边 1024，保留 PNG 透明度；几何、材质参数、动画与非图像缓冲数据保持不变。近距离纹理清晰度可能降低，不声称画质完全无损。
- 发布包排除未使用的旧 `board_scene.glb`，保留当前场景、2D 回退资源和全部列车资源；列车校验清单同步更新。
- 发布源逐项校验市场的单文件 16 MiB、解压总量 32 MiB、根目录清单和入口要求。插件 ID 仍为 `local.sakura.boardgame`。

## 上一预览版主要变化

- 真实 Agent 的状态读取、一次性决策票据、合法参数校验、提交回执及重复提交保护。
- 修复黑列车角色掷骰和岔路/自选骰续步无人调度、离屏过渡动画停摆，以及自动行动轮询唤醒等问题。
- 修复单节点移动结算与塔内破产终态清理。
- Agent 历史快照无损去重，保留所有行动记录与权威事实，不改持久存档格式。满历史离线样例体积减少约 66.7%；实机样例约 29.3% 字符减少，二者不可混为相同收益。
- 解说提示明确骰点、剩余步数、当前待决策方和已提交结果，仍允许角色感受、玩笑及简短策略表达。

## 已知问题和测试边界

- **模型请求可能超时**。快照去重没有根治此问题。失败或过期后可手动重试或选择单次算法代操作；结果不确定时先恢复连接并核态，不自动重复。
- **解说可能出现事实偏差**，例如位置滞后、错误交棒或混入历史事件。请以棋盘和结算记录为准；不要根据解说重复购买、掷骰或领取奖励。
- 语音依赖宿主 TTS 插件及当前角色的语音配置；合成成功不等于播放完成。
- 黑列车探险期间不能切换到另一种游戏；需先完成探险。部分锁定提示尚不够明确。
- 本轮开发环境完成 **274 项 Python 回归和15个界面测试脚本**，不等于完整实机流程。真实 DeepSeek 有界验证包括聊天话题切换、当前轮次问答及暂停/恢复；棋局未推进。模型仍可能无视短答要求，实测要求一句时仍生成了两段。不能据此保证其他供应商或长局表现。
- 当前 1.3.6 环境下的整局大富翁终局、完整列车返程、塔实机分支与完整五子棋重测尚未全部闭环；新安装环境仍欢迎反馈。

## 排障

- 从 Sakura 重新打开棋盘获取当前端口；不要继续使用旧地址。
- 响应丢失时不要立即重复操作，服务端可能已经执行。恢复连接后先查看状态。
- 查看 Sakura 数据目录 `logs/sakura-plugins.log`、`sakura-runtime.log`；Agent 详细追踪位于 `sakura-agent-trace.log`。报告问题时提供时间、版本、错误码及必要片段，**先删除密钥、私人聊天和记忆内容**，不要上传整个数据目录。
- 更新源码必须使用完整插件目录，包含 `agent_snapshot.py`、`board_server.py` 和全部网页模块，不能只复制主 Python 文件。

## 开发

[跨插件开发经验与验收清单](<https://github.com/0115ayasakura/Sakura-boardgame/blob/main/docs/sakura-plugin-development-lessons.md>) 整理了本项目的授权执行、异步事务、上下文隔离、呈现状态机和市场发布经验；[v1.0.3-pre 更新说明](<https://github.com/0115ayasakura/Sakura-boardgame/blob/main/docs/releases/v1.0.3-pre.md>) 说明本次发行边界。

源码目录 `sakura_boardgame/`，回归目录 `boardgame_tests/`。Python 建议使用 `-B` 避免生成缓存。可分别运行：

```text
python -B boardgame_tests/test_agent_turns.py
python -B boardgame_tests/test_agent_snapshot.py
python -B boardgame_tests/test_action_transactions.py
node boardgame_tests/test_auto_poll_wakeup.mjs
node --test sakura_boardgame/tests/board3d_scheduler.test.mjs
```

部分旧预览/角色测试默认读取本机角色包或启动浏览器；运行前检查参数。`test_agent_commit_schema.py` 需要同级 `Sakura/` 宿主源码，或通过 `PYTHONPATH` 指向 Sakura 源码目录，以验证真实宿主 Schema 注册器。默认总测试入口未覆盖全部资产旁测试，脚本退出成功也可能包含跳过项，勿据此声称完整实机通过。

发布包通过白名单构建，排除本地 `config.json`、缓存、测试和存档；源码测试保留在仓库。安装后产生的数据由宿主保存在插件数据目录，不写回发布包。
