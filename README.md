#  Sakura 棋盘游戏插件

给桌面角色扮演应用 [Sakura](https://github.com/Rvosy/Sakura) 写的**双人回合制桌游插件**：
引擎管规则，角色管解说。你和夜乃樱在同一张**可拖拽的网页棋盘**上对局，她在每一步给出口吻一致的解说。

完全使用 **Python 标准库**（无第三方依赖），美术除角色立绘外全部**程序生成或本地 AI 生成**。

内置两个游戏：

| 游戏 | 玩法 |
|---|---|
| **大富翁** | 「第二横滨市」城市地图上的地产经营：掷骰沿街道走格、遇岔路选方向、买地收租升级抵押、四街区垄断加成、九种格子、24 张原作事件卡；破产判负，回合上限按**总资产**定胜负 |
| **五子棋** | 十五路棋盘；开局双方各掷骰决定先后手；夜乃樱的棋由内置 AI 代算，可选难度与棋风 |

## 特性

**网页棋盘（全程可交互，不占聊天）**
- 拖拽平移 / 滚轮缩放；开局视角有缩放下限，格子和棋子不会小到看不清
- **地图来源可切换**：手工城市图「第二横滨市」/ 程序生成的随机地图（侧栏一键切换，下一局生效）
- 城市图：四个街区用柔和色块标出，底层有立体建筑、绿地、海与河道；**地标画成地图图钉**，钉尖指向路线上的锚点
- **地标插画**：29 块地产各有 AI 生成的一图一景，图片缺失时自动退回通用图标
- **行进方向由地图规定**：主环单向（从起点出发第一格必定是学园正门），主环上画着蓝色方向箭头；支街双向
- 移动时把走过的路线画成一条彩线，棋子沿线滑行
- 事件效果直接写在对局记录里（如「（效果：获得 ¥110）」「（-¥300）」），不用心算

**随机地图**：抖动的格子位置 + 贪心最近邻成环 + 2-opt 松解，保证**主路不自交叉、支线不穿主线、支线至少跨过两个节点**；间距按 1.95 格铺开，图钉不会互相挤。（`tools/check_random_rules.py` 可复算这些指标）

**五子棋 AI**：纯标准库自研棋型评估 + alpha-beta，难度（入门/进阶/困难）× 棋风（0–100 进攻倾向）都会真正改变选点，并给出落子理由供角色解说。

**出问题了也能玩**：角色的工具调用未必可靠，所以插件做了三条兜底——棋盘地址每轮都在角色上下文里、开局回复里带地址、**网页自己就能开局**（点掷骰子时若还没对局会自动开一局）。

## 安装

从 [Releases](https://github.com/0115ayasakura/Sakura-boardgame/releases) 下载 `sakura-boardgame-plugin.zip`（或整包
`sakura-boardgame-v1.1.1.zip`，里面就是这个插件 zip + `README.md` + `角色卡补充.txt`），然后：

1. Sakura「设置 → 插件 → **安装插件…** → **从 ZIP 安装…**」，在文件对话框里选中插件 zip。
   （也可以选「从文件夹安装…」，指向解压出来的 `sakura_boardgame` 目录——含 `plugin.yaml` 的那一层。）
2. 装好后插件默认是**未启用**状态，在插件列表里打开它的开关。
3. 启用后聊天侧出现 6 个 `boardgame_*` 工具，并启动一个本地棋盘服务器（仅监听 127.0.0.1）。
4. 「插件设置」可调：地图来源、骰子面数、随机地图规模、五子棋难度与棋风、**打法性格**、自动打开棋盘、角色自动反应。

> 需要 Sakura 1.1.0 及以上（Plugin API v4；1.1.1 / 1.1.2 已验证）。本插件用系统级浏览器调用打开棋盘，
> 不依赖已移除的 Playwright 网页插件。
>
> **更新要先卸载**：Sakura 不允许同一个 `id` 覆盖安装，先在插件页点「卸载插件」——插件设置与数据会保留——
> 再按上面的步骤装新版。

## 开发与自测

```bash
python boardgame_tests/test_engine.py          # 引擎 30 项测试

python boardgame_tests/test_plugin_smoke.py    # 插件集成测试（假宿主，含开局/网页操作/存档）
python boardgame_tests/preview_server.py monopoly   # 本地起一局，浏览器看棋盘
python tools/preinstall_check.py               # 安装前体检（资产齐全 / 无硬编码路径）
python tools/map_report.py                     # 打印城市图结构：主环顺序、支路、路口、地产归属
python tools/check_random_rules.py             # 随机地图指标：锐角 / 交叉 / 支线跨步 / 最小间距
```

改完跑 `python sakura_boardgame/city_map.py`，输出「校验：通过 ✓」才算改对。

## 她的打法性格（读角色卡）

大富翁里她买不买地、升不升级、岔路走哪边，**由角色卡正文推出来**：插件开局时读宿主的
`sakura.host.character.current()["systemPrompt"]`（就是 `characters/<角色>/card.md`），
按里面的措辞给「谨慎 / 好胜 / 好奇 / 心软」四个倾向打分，换算成四个参数——买地前留多少底金、
升级意愿、拐进支街的倾向、领先 25% 以上时会不会放一块地给玩家。

- **改角色卡就能改她的棋风**（下一局生效，不用重启插件）；插件设置里也能用
  「稳健 / 进取 / 随性 / 温柔」直接覆盖，选「跟随角色卡」恢复默认。
- 她的上下文里会写明「你现在的打法性格：……」，所以**解说和落子是一致的**。
- 夜乃桜那张卡推出来的大致是：好胜 + 好奇 + 心软，买地前留 ¥270 上下、升级意愿 74%、拐支街 63%、让地 25%。

## 经济平衡与调参

大富翁的数值是**用跑批定的**，不是拍脑袋：`boardgame_tests/econ_report.py` 能一次跑 200 局并统计
租金事件、垄断出现率、破产率、买卖双方胜率。当前（200 局、双方都按她的买法）：

| 指标 | 数值 |
|---|---|
| 结束方式 | 破产 10% / 打满上限 90% |
| 租金事件 | 5.5 笔/局（单笔中位 ¥90、最高 ¥540） |
| 垄断出现率 | 75% 的对局（终局被买走 16.9/29 处地产） |
| 买地 vs 只攒钱 | 50% : 50%（判定按总资产，买地不吃亏也不无脑占优） |

调参旋钮都在 `sakura_boardgame/engine.py` 顶部：`MONOPOLY_PRICE_UNIT`（地价单位）、
`MONOPOLY_START_CASH` / `MONOPOLY_PASS_START`（一局里有多少钱）、`MONOPOLY_ROUNDS_PER_CELL`（局长度）、
`MONOPOLY_HOLD_SHARE`（垄断门槛）、`MONOPOLY_PROPERTY_SCORE`（终局地产折价）、`MONOPOLY_RENT_DIVISOR`（租金比例）。
改完跑一次 `econ_report.py` 就能看到前后对比；`econ_ledger.py` 会校验"钱没有凭空多出来或漏扣"。

## 关于开发方式

**本项目的全部代码与文档均为 AI 编写**，在人工提出需求、验收与反馈的协作下完成，**不含任何手写代码**。
美术资源同样不是手工绘制：地图（街区、建筑、绿地、水体、路网）由 `city_map.py` 程序生成，
35 张地标插画由本地 ComfyUI 生成，图标与玩家头像是代码里的内联 SVG。

## 已知限制

- **角色不一定主动调用工具**：实测在聊天里说「开一局」她可能只做口头解说（她的角色卡写着"操作在网页上完成"）。
  明确要求（「调用 boardgame_start」）时也有概率不调用；插件侧已做兜底，不依赖她也能玩。
- **自动播报没有语音**：网页「请夜乃樱行动」触发的那轮解说走的是插件注入通道，宿主不为其生成语音；
  想听她说话，就在正常聊天里问她一句，但是大概率是单纯解说没有对棋子的操作。


## 未来计划：3–4 人局（暂缓）

跑批测算显示现在这张 57 格 / 29 处地产的城市图**其实更适合 3–4 人**：一局里的钱 ≈ 人数 ×（起始 + 工资），
4 人时约 ¥4600，而棋盘总价 ¥3420（钱/地价 ≈ 1.35）——**能把棋盘买空**，租金成为主要资金流。
双人局只有 0.77，只能买走一半（这也是起始资金从 ¥1000 调到 ¥1400 的原因）。

但**Sakura 本体与现有第三方插件暂不支持多开角色 agent**，多出来的座位只能是"无名 AI"，
所以先记为将来打算做的事。要动的地方：收入方式（绕圈工资 → 每回合津贴，或上限按人数放大）、
引擎 N 人轮转与结算、插件的 AI 座位、网页的棋子位与玩家面板。
