# v1.1.1 Sakura 棋盘游戏插件（大富翁 + 五子棋）

Sakura 桌面角色的双人回合制桌游插件：引擎管规则，角色管解说，全部操作在一张可拖拽的网页棋盘上完成。

## 这一版（v1.1.1）改了什么

**玩法与经济平衡**（这一版的重点，全部用 `boardgame_tests/econ_report.py` 跑批定的）

- **回合上限判定从"看现金"改成"看总资产"**（现金 + 地产现价 ×0.6）。旧规则下买地把现金换成了不计分的资产，
  跑批配对实验显示"买地的一方胜率只有 6.5%、全程不买地 93.5%"——买地是纯亏。改完回到 **50% : 50%**。
- **垄断条件从"整条街区全持"放宽到"持有一半（至少 2 处）"**。旧条件在一局里根本凑不齐（实测 0% 触发），
  翻倍租金这条规则等于不存在；现在 **75% 的对局**会出现垄断。
- **地价从 ¥100/200/300 降到 ¥60/120/180**，起始资金 ¥1000 → **¥1400**、起点工资 ¥200 → **¥250**：
  一局里的钱 ÷ 棋盘总价 从 0.77 提到 1.07，被买走的地产 13.8/29 → **16.9/29**，租金事件 2.2 → **5.5 笔/局**。
- **回合上限从"格数"改成"格数 ×1.5"**（城市图 57 → 86 步，每人约 1.5 圈）——旧上限只够绕 0.9 圈，
  工资只能领一次、租金几乎收不到。
- **强制抵押改按现价回收**（原来用基础价，涨价后比主动抵押少拿三分之一）；卖出价也从基础价改成现价。
- **她的打法性格现在由角色卡正文决定**：插件读宿主的角色卡全文（`sakura.host.character`），
  按里面的措辞推出"谨慎/好胜/好奇/心软"四个倾向，换算成"买地前留多少底金、多爱升级、多爱拐支街、
  领先多了会不会让地"。**改角色卡就能改她的棋风**（下一局生效）；插件设置里也能直接用预设覆盖。
- **棋盘高亮修正**：城市图的路网/格子/棋子/金圈此前不在同一坐标系（金圈离金线终点 62px），
  现在统一；岔路高亮延伸到"下一个岔路或步数用尽前的最后一格"，并在落点格上套金色呼吸圈；
  本回合的出发格用紫色虚线圈标出。
- 对局记录不再混入"给模型的工具指令"（那些只留在工具返回值里）。

**工程**

- 新增跑批与校验工具（`boardgame_tests/`）：`econ_report.py`（含 `sweep` 模式）、`econ_ledger.py`
  （经济不变量：现金不为负、转移零和、金额与现价一致、租金一笔对一笔）、`econ_money.py` /
  `econ_players.py`（起始资金、地图规模 × 人数的适配性）、`econ_pacing.py` / `econ_trace.py`（节奏与逐笔流水）、
  `preview_fork.py`（造确定性岔路做验收）。引擎测试 30 项、插件冒烟测试、全新安装模拟全绿。
- 地图与几何校验脚本（`boardgame_art/`）：`check_repo_sync.py`（工作区 vs 仓库 vs HEAD）、
  `check_release_zip.py`（发布包里的文件是不是当前源码）、`dom_probe.mjs` 等无头浏览器 DOM 验收脚本。

## 包内容

| 文件 | 说明 |
|---|---|
| `sakura_boardgame/` | 插件本体。**Sakura → 设置 → 插件 → 安装插件 → 从 zip 安装**，选中本 zip 或解压后指向 `sakura_boardgame` 文件夹均可 |
| `角色卡补充.txt` | 粘进角色卡的一节提示词（开局必须调用工具、地名说话、解说方式、打法性格、输赢反应）。**强烈建议使用**，它决定角色的表现是否到位 |
| `README.md` | 项目说明（含规则速查、当前平衡数值、如何改地图/改性格） |

## 主要特性

- **两种大富翁地图**：手工城市图「第二横滨市」（57 格 / 四街区 / 29 块地标 / 单向主环，起点出发第一格必是学园正门）
  + 程序生成的随机地图（主路不自交、支线不穿主线），侧栏一键切换
- **网页棋盘**：拖拽缩放、地标地图图钉、AI 生成的一地一景插画（35 张）、移动路线绘制、岔路选点动画、
  事件效果直接写进对局记录
- **五子棋 AI**：纯标准库棋型评估 + alpha-beta，难度 × 棋风都会真实改变选点，落子理由供角色解说
- **不依赖模型调用工具也能玩**：棋盘地址每轮注入角色上下文；网页侧点掷骰子即可自动开局；
  「请夜乃樱行动」一次点按走完她的整个回合
- 聊天输入框「+」菜单里有 **「打开棋盘」** 入口（没对局就自动开一局）
- 棋盘服务器闲置 30 分钟自动关闭，再次访问按需重启

## 环境

- Sakura 1.1.0+（Plugin API v4；1.1.1 已验证兼容）
- 纯 Python 标准库，无第三方依赖

## 已知限制

- 角色未必会主动调用工具（她常按角色卡的"解说"语气开局）——此时直接打开棋盘网页操作即可
- 网页「请夜乃樱行动」触发的解说没有语音（插件注入通道不经过宿主 TTS 授权）；想要语音，在正常聊天里问她
