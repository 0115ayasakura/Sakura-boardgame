# v1.0.3-pre

适用于 Sakura 1.3.6 及以上的预发布版。插件 ID 仍为 `local.sakura.boardgame`，安装前请备份插件数据，更新不会要求删除存档。

## 本次更新

- **先选完，再解说**：角色完成当前授权内的连续选择后统一收尾，减少每个子动作先播旁白的等待。每张 token 仍只有一个合法动作，只有成功回执返回 continuation 才继续，最多8步；不会代走玩家、跨塔或自动开始下一次全新掷骰。
- **超时恢复**：失败或过期后可明确选择「由算法代操作」，仅完成当前动作，不改变后续 Agent 模式；旧票撤销，迟到提交不能重复走棋。未知提交结果仍先核态，不自动重发。
- **暂停与继续**：暂停状态随存档保存，撤销旧 Agent 票据并阻止后续走棋；可收起/查看棋盘，回来继续原待选项，保留自动模式选择。暂停不承诺停止已经生成的语音。
- **聊天话题隔离**：只在本轮明确涉及桌游或插件主动请求时注入棋局，不再因为旧存档仍存在，就持续把普通闲聊当作正在玩。
- **等待和失败反馈**：展示当前阶段、耗时和按钮禁用原因。黑列车失败信息保留在事件卡内；不确定结果取得权威状态后才提供手动恢复，不自动重发。
- **结果阅读**：金额、道具、胜负等重要普通事件需明确确认，轻提示仍自动收起；旧计时和确认回调不能关闭下一张卡，保留黑列车逐条确认、返程和结算保护。
- 修正连续选路后的骰点呈现、深色主题控制条对比度、收起棋盘的实际隐藏行为；内置引导移除先解说后动作等过时要求。

## 安装

下载本 Release 的 **sakura-boardgame-plugin.zip**，通过 Sakura 的插件 ZIP 安装/更新入口导入后启用。不要手工删除同 ID 插件的数据目录。GitHub 自动 Source code 属于根清单发行树，市场使用独立 `registry` 分支及本标签；开发源码和测试在 `main`。

## 验证与边界

- 实际发行源码树复跑：274项 Python 回归、15个界面测试脚本及插件集成烟测通过。验证真实宿主 Schema 的测试需提供对应 Sakura 源码，不把脚本数量当成完整实机流程。
- 官方 Registry 校验通过：96个文件，解压总量31,904,087字节（小于32 MiB），最大单文件9,502,668字节（小于16 MiB），插件 ZIP 为21,166,780字节。公开 source commit 会在发布前再次下载、重建并与本地产物逐字节比较。
- 正式安装实测：暂停→收起→查看→恢复后，局号、引擎棋局、待选项和自动模式不变，未推进棋局。控制版本改变用于隔离旧请求，不代表新增了行动。
- 实际模型仍可能过长、超时或误述；要求一句的实测仍生成两段。请以网页及引擎回执为准，不因旁白重复操作。
- **不包含宿主 patch**：本机曾调整 Sakura 普通/Agent 分段协议，该修改不属于本插件 ZIP。公开包仅更新插件内置引导，不保证原版宿主或自定义引导得到相同短答效果。
- 黑列车失败恢复有生产代码隔离回归；未在真实存档注入网络故障，也未重新完成整局大富翁终局、完整列车返程及全部塔分支验收。
- 保留上一版为市场体积限制优化的资源，不把开发目录的高分辨率素材覆盖回发行包。第三方美术与依赖声明随包保留。
