# v1.0.2 Preview — Sakura 市场收录兼容修正

此版修复 v1.0.1-preview 无法被 Sakura Registry 收录的包结构与资源体积问题，不修改存档、棋局规则或 Agent 权限。

## 修正

- 市场分发源移至 `registry` 分支，版本标签指向根目录包含 `plugin.yaml` / `plugin.py` 的完整插件。`main` 保留开发源码、测试与构建工具。
- 插件身份保持 `local.sakura.boardgame`，版本为 `1.0.2-preview`，最低 Sakura 1.3.6。
- 两份场景中的大纹理最长边缩至 1024，PNG 保留透明度；不增加 Draco/KTX 等解码器。非图像缓冲字节、几何、材质参数、节点、动画均校验不变。近距离贴图细节可能变软，不宣称画质无损。
- 分发排除未使用的旧 board_scene.glb；当前普通场景、黑列车、图标、POI、2D 回退资源均保留。黑列车哈希清单同步更新。
- 源文件总量 31,877,795 bytes（约30.40MiB），最大单文件 9,502,668 bytes（约9.06MiB），均低于市场 32MiB / 16MiB 限制。
- 使用官方 Registry `package_source()` 验证根目录、身份、入口、文件数及体积限制，检查 GLB 图像解码、缓冲范围和列车资源哈希。

下载 `sakura-boardgame-plugin.zip`，通过 Sakura 插件管理器安装。更新前备份插件数据目录；不要删除存档。旧 v1.0.1-preview 标签保留，不重写历史版本。

## 仍然存在的预览边界

模型请求超时、旁白事实偏差仍可能出现，本次没有根治。完整实机终局流程尚未全部闭环；离线资源与调度回归不等于真实浏览器渲染或模型全流程验收。美术来源与第三方许可说明见包内 THIRD_PARTY_NOTICES.md；第三方美术不受本项目 MIT 许可覆盖。
