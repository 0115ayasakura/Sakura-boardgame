# v1.0.1 Preview

适用于 Sakura **1.3.6+**。请下载附件 **sakura-boardgame-plugin.zip**，通过 Sakura 插件管理安装并启用。GitHub 的 Source code ZIP 是开发源码，不是安装包。

## 主要变化

- 大富翁城市/格子地图、商店与道具、塔探索、黑列车事件；五子棋与当前角色的真实 Agent 对弈。
- 完善 Agent 合法动作参数、决策票据、提交回执与重复提交保护；失败时不偷偷切回算法。
- 修复黑列车掷骰与 route/dice 续步调度、离屏过渡动画卡住、自动轮询唤醒等问题。
- 修复单节点移动结算与塔内破产清理。
- 行动历史快照无损共享去重，不删除历史、不更改存档格式；满历史离线样例约减少 66.7% UTF-8 字节，实机样例约减少 29.3% 字符。
- 调整解说提示，区分骰点与已走距离、待选分支与已完成行动，同时保留角色口吻。

## 已知问题

- 模型请求仍可能超时；快照缩小不等于根治。失败后请先确认棋盘状态，不要盲目重复操作。
- 模型解说仍可能误报位置、交棒或混入旧事件。现金、票根、收益与实际行动以棋盘记录为准。
- TTS 需要单独配置语音插件及当前角色模型。黑列车探险进行中不允许切换游戏。
- 这是 Preview：52 个不同离线回归脚本有效通过，近期 DeepSeek 有界续测四次提交成功，但完整五子棋重测、大富翁终局、塔与黑列车返程的全部实机分支尚未闭环。
